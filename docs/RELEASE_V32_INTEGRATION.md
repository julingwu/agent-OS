# 3.2.1 · 工作空间功能整合

本版以 `main` 的 `e9bf659`（专业工作台与任务全流程修复）为基础，选择性吸收
`sync/v3.2` 的 `2fcc8fa`。保留工作台、任务中心、响应式布局、独立产物预览票据、
任务停止/重试保护和 DeepSeek DSH 配置，在现有界面中接入工具与治理能力。

## 吸收的能力

| 能力 | 本版的行为 |
| --- | --- |
| 外部 HTTP MCP 工具 | 管理员添加、编辑、停用、探测连接，为指定员工分配工具；真实 ACP 新会话收到当前授权配置 |
| 邮件配置与草稿 | 按租户和实体保存 SMTP 配置；管理员可明确发送测试邮件；AI 工具只准备本地 `.eml` 草稿 |
| 经验审核 | 自动沉淀、手动新增和编辑均进入待审核，审核通过后才参与新任务；保留版本和审核记录 |
| 强制交付规则 | 对当前运行的交付物检查禁用用语，保留规则版本、规则哈希、产物校验和与命中证据；人工验收不能绕过 |
| 岗位提示 | 从实际员工岗位生成提示，用户伪造提示标记不能抑制；提示不替代服务端授权 |
| 项目恢复 | 被否决项目接受修改后的完整需求，重新评审；保留完成的工作、历史闸门和历史交付文件 |
| 租户基础 | 身份、实体、任务、运行、产物、会话、项目继承租户；已存在数据只做迁移和缺失值回填 |
| 错误与界面反馈 | 新入口沿用当前工作台风格，显示保存、审核、连接失败及恢复状态 |

## 整合时修复的问题

- UI 同时检查有效身份、租户和实体权限；请求头不能切换租户。列表、直接 ID、
  成员请求体、审批、项目与聊天都使用相同边界。全局配置由部署管理员维护。
- 真实 ACP 项目保存并沿用经过验证的实际发起身份，为构建任务指定同属员工，
  让岗位提示和工具授权具备明确归属；身份撤销或归属不一致时拒绝执行。
- 第二租户可正常登录、重载并访问自己的组织和任务；可选数据读取失败不会清除
  有效登录。全局配置写入仅允许总部实体 CEO 或总部租户 system 部署管理员，
  同租户的子公司 CEO 不能修改部署配置。
- 同页会话过期或切换账号时清除上个身份的列表、任务详情、选择和数据弹窗；旧请求
  的成功或 401 响应不能恢复旧数据、覆盖新身份或注销新登录。
- 通用签名事件接口仅接受执行开始、成功、失败、取消；验收结果必须由验收流程
  产生，不能用 `review_passed` 事件绕过当前强制规则。
- 审批通知按审批所属租户和实体选择会话，外部会话关联会被拒绝；没有合适会话时
  留在所属审批中心。决定和授权应用的审计记录也使用实际归属。
- 组织查询和项目挑选员工限制在当前实体范围，避免其他租户信息进入模型上下文。
- 工具服务密钥不返回浏览器；修改服务地址会清除旧密钥。探测不跟随重定向，
  错误、日志、实时流及 Trace 会屏蔽工具认证串，包括 JSON 键名中的回显。
- ACP 续跑在启动和发送提示前重新检查身份、租户、员工、授权配置指纹和会话所属任务。
  撤权、解雇、租户停用、密钥改变或跨任务会话均不能继续沿用旧授权。
- 经验审核使用所查看的版本和待审核状态作并发条件；旧页面不能批准修改后的内容，
  也不能覆盖另一个管理员已完成的审核。
- 红线只扫描当前提交，修正重试不会永久沿用旧失败；HTML 检查可见文案。
  读取或检查失败保持阻塞，新的强制规则在项目验收和发布前再次检查。
- 研讨结论必须包含有效的明确表决；缺失、未知结论和模型不可用均不能解除旧否决。
  项目重试有原子占用标记；中断后恢复为可修订的阻塞状态。
- 项目执行测试的非零退出和超时不再误报成功。历史交付物使用独立文件保存。
- 邮件草稿完整写入后原子替换，验证已有内容哈希才认定重复；空文件、半写文件和
  中断的清单可以在重试时修复。该机制不发送邮件。
- 任务中心初始搜索计时器不再把快速翻页的用户拉回第一页；员工授权加载完成前
  禁止保存，避免切换员工时误清空授权。

## 范围与限制

这一版提供本地工作空间的隔离基础，没有加入计费、订阅或完整 SaaS 开户流程。
缺少有效发起身份的旧项目在真实执行模式下会明确阻塞，不会自动取得系统权限；
需要由实际负责人重新立项。离线演示模式仍可使用已有模板流程。
HTTP MCP 是管理员明确授予的服务能力；远程工具在 DSH 内执行，通知后的取消不能
保证阻止已经发生的远程副作用。本版不承诺任意外部工具的逐次调用审批或调用中撤权。

AI 邮件网关仅暴露 `prepare_email`，返回 `delivered: false`。自动真实发信需要独立的
精确内容审批、持久发送状态和不明确结果的核对机制，因此本版保留为草稿。
SMTP 的“发送测试邮件”是管理员主动操作，与 AI 任务重试分开。
配置与网关使用方式见 [外部工具说明](EXTENSIONS.md)。

审批提醒保留在站内审批中心和所属会话。旧的全局企业微信收件人没有租户、实体归属，
本版审批提醒不会自动外发到该目标；部署租户专属外部提醒需要先建立明确的目标归属。
