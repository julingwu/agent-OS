# AI 工作空间与流程验证

首页现在为工作台，展示真实任务统计、可筛选任务列表、AI 团队和审批入口。任务中心支持服务端搜索、状态筛选与分页；“查看”打开指定任务。新建任务可选择直接执行的 AI 员工、协作群，或创建多阶段项目的 CEO 调度台。

验收、驳回、重试均有确认表单。驳回须填写原因；重试沿用任务和执行会话，保留当前配置的 runner。已完成或取消的任务不会重复出现执行操作。运行详情中的验收进度仅表示判据通过比例，Token 数量单独展示。

产物预览使用短期、仅限单个产物的访问票据，预览页面不会收到登录会话凭据。安全预览会屏蔽外部脚本、图片、样式等资源，完整内容可下载查看；HTML 的内联交互、文本与图片预览保留，焦点在预览正文中时也能用 Escape 关闭。

## 本地运行

1. 按项目 README 安装 Python 与 Web 依赖，配置本机 `.env`。
2. `npm --prefix web run build`
3. `python -m uvicorn app.main:app --host 127.0.0.1 --port 8077`
4. 打开 `http://127.0.0.1:8077/app/`，用本机身份登录。

已有启动器的本机安装可直接继续使用启动器。前端源码改变后需要重新构建；后端源码改变后需要重新启动对应服务。

## 隔离浏览器回归

不要对日常数据库运行自动化测试。以下助手复制应用与验收脚本到独立目录，并关闭真实模型及外部消息：

```powershell
npm --prefix web run build
python tools/serve_ui_test.py --port 8078
```

助手输出测试地址、测试身份 ID 和独立数据目录。它只在这个测试进程启用快速登录，正常服务的配置不变。

每次启动都必须使用新的空目录；默认会自动创建独立临时目录。若指定 `--data-dir`，该目录必须位于仓库之外，且不存在或为空；助手会直接拒绝非空目录，不会合并或覆盖上次的测试目录。端口范围为 1–65535，正常服务端口 8077 禁止用于测试。

保留该进程，另一个终端运行：

```powershell
$env:AGENT_OS_TEST_URL = 'http://localhost:8078'
$env:AGENT_OS_TEST_ID = '<助手输出的 test_identity_id>'
npm --prefix web exec playwright install chromium
npm --prefix web run test:browser
```

测试覆盖创建任务、等待执行、产物预览与下载、驳回原因、同任务重试、验收及刷新持久化；另检查多种窗口宽度、导航、上传、弹层键盘操作与界面错误。测试产物属于合成数据。退出助手即可关闭测试服务，不会停止正常服务。

安全预览回归会轮换隔离合成身份的登录凭据，再通过正常登录验证 cookie 与 Bearer 路径、单文件短期票据及外部资源屏蔽；仅限这个临时测试环境，不可用于日常或共享账号。

## 后端与真实执行

`tests/test_ui_task_actions.py` 覆盖任务状态、授权范围、分页、异步重试、进程终止、取消竞态、审批与产物删除。运行 Python 测试前，使用独立 DB_PATH/M0_WORKSPACE，清空模型 API Key 并关闭外部消息；不要加载日常工作数据。

真实执行应另外使用已配置的 DSH/模型做小范围验证，保留真实 runner、执行结果和独立复核证据。模拟测试通过不表示真实集成已经通过。不得在日志、截图、文档或协作消息中放入密钥。
