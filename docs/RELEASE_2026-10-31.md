# 2026-10-31：统一启动与受控自迭代版本

日常只需双击仓库根目录的 `Start.cmd`。

## 包含的改动

- 程序集中到 `program/`，数据、工作区和输出保留在根目录的独立目录。
- Start 自动管理网页服务和本机执行程序，就绪后打开浏览器。
  健康实例直接复用，旧实例按项目归属清理；正在工作的实例保留并提示。
- 通过启动锁避免重复启动，校验进程身份，兼容 Windows 未提供端口 PID 的情况。
- 红绿轨采用“先验证、等待工作结束、再切换”的发布流程，记录发布阶段和失败结果。
- 备用轨不执行任务恢复和调度，切换后重连事件流和设备。
- 追加消息不重复排队；晚到消息会接续处理；停止请求不再提前伪造任务结束。
- 包含本轮 Agent 自我迭代的活动面板：折叠展示、最近五条高度限制、滚动回看和跟随最新动态。
- 前端源码与本次构建的静态产物同步发布。

## 验证

- 相关后端、启动器、事件流和工具回归：128 项通过。
- 最新桌面前端：Vite 生产构建通过。
- 真实双后端与确定性模型验证：绿→红、红→绿、Agent 在本轮内请求发布、设备重连及历史读取通过。
- 本机统一启动、重复启动复用、页面可访问已验证。

维护入口为 `program/Verify.cmd`；详细边界见 [受控发布说明](CONTROLLED_RELEASE_VALIDATION.md)。
本版使用浏览器界面，未重新打包 EXE/APK，不承诺运行中任务迁移或独立旧代码版本回滚。
