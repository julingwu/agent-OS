## 2. 产物预览

- 后端：`GET /ui/files/{artifact_id}/preview`，按扩展名给 content-type（html/css/js/md/svg/png…），
  响应头带：

  ```
  Content-Security-Policy: sandbox allow-scripts allow-popups; default-src * data: blob: 'unsafe-inline';
                           connect-src 'none'; frame-ancestors 'self'
  X-Content-Type-Options: nosniff
  ```

  意思是：**能跑 JS、能渲染，但被关进不透明来源，拿不到控制台 Cookie/Token，也发不出任何请求**。
- 鉴权：`<iframe>` 带不了 `Authorization`，所以预览链接用 `?t=<签名票据>`；票据本身是
  HMAC 签名 + 7 天过期，不新增可伪造面。前端 `referrerPolicy="no-referrer"`。
- 前端：任务卡的产物行与文件库每行都有「预览」，弹窗里嵌 iframe。

**证据**：`docs/v12_preview.png` —— 弹窗里渲染的是 AI 早前写的双十一落地页（36,288 B）。

## 12. Cordis 创造模式（preset）

**问题**：外壳沙箱里跑 `npm install` 会被 DSH 的提权审批卡死（§51）。
**做法**：不跟外壳死磕，改用 DSH 自己的权限预设。

| 环节 | 实现 |
|---|---|
| 数据 | `ai_employees.preset`（`standard` / `cordis`），迁移已入库 |
| 开关 | `PATCH /ui/employees/{id} {"preset":"cordis"}`，非法值返回 400，写 `agent_edited` 审计 |
| 运行 | `runner_acp` 读取任务 owner 的 preset：`cordis` → `DSH_PERMISSION_MODE=danger-full-access`、**跳过外层 Low 完整性沙箱**，并写 `cordis_enabled` 审计 |
| UI | 员工面板显示 preset 胶囊 + 「开启/关闭创造模式」按钮 |

**实测**（任务 `T-00e2f68a686e4567`，owner=小构/架构师）：

```
exec: failed 9413 tok
cordis audit rows: [('cordis_enabled', '{"preset": "cordis", "mode": "danger-full-access"}')]
```

审计里出现 `cordis_enabled` 即代表通道打开；那次 failed 是 3k 预算不够一轮（预期）。

**风险边界（必须记住）**：`cordis` 等于**这台机器上该 Agent 拥有完全访问权**（能写任意路径、能装包、能联网），
且不经过审批。只给架构师这类需要自建工具的角色开；业务 Agent 保持 `standard`。

## 18. v1.3.4：干掉 UAC 弹窗

**症状**：每次启动/新建沙箱目录都会弹 `icacls.exe` 的 UAC 框。

**根因（实测，不是猜）**：

| 试验 | 结果 |
|---|---|
| `icacls <仓库里的目录> /setintegritylevel` | `拒绝访问 (5)` → 旧代码走 `Start-Process -Verb RunAs` → **弹 UAC** |
| `icacls <用户目录里的目录> /setintegritylevel` | **成功，无提权** |
| `SetNamedSecurityInfoW(LABEL_SECURITY_INFORMATION)` on 仓库目录 | `5 ACCESS_DENIED` |
| 同上 on 用户目录 | 返回 0，但标签没生效（SACL 需要的能力当前 token 不具备） |

仓库 `C:\oaagent-m0` 的 ACL 属 `BUILTIN\Administrators`，我们只拿到 `(I)(M)`——没有 WRITE_OWNER，
所以打标签必须提权；用户自己的目录天生是 owner，`icacls` 静默就能写。

**改法**：

1. 工作区根从 `C:\oaagent-m0\workspace` 迁到 **`%LOCALAPPDATA%\oaagent-m0\workspace`**。
2. `sandbox_cmd` 在**父进程**里给「工作区根 + 本次任务目录」打标签，子目录靠 `(OI)(CI)` 继承。
3. `set_dir_low` 顺序：已是 Low → 原生 API → 静默 icacls；**全部失败就抛错**。
4. **删掉所有 `-Verb RunAs` 兜底**——它能成功，但每次都要董事长点“是”。

**验证**：

| 项 | 结果 |
|---|---|
| 打标签耗时 | 0.07s（根目录），任务目录直接继承 `(I)(OI)(CI)(NW)` |
| 真实任务 | `RUN-e14a7b38d6e1477b` succeeded，8,666 tokens，产物落在新工作区 |
| 目录标签 | `Mandatory Label\Low Mandatory Level:(I)(OI)(CI)(NW)` |
| UAC | 代码里已无 RunAs 路径；`grep -rn "Verb RunAs"` 只剩注释 |

**追加修正**：工作区根**不能**打 Low —— 打了之后 Low 子进程可以往根目录写，
逃逸探针 `test_m0_20` 立刻变红（`DONE ESCAPE_OK`）。最终方案是：
根保持 Medium，**每个任务目录单独打 Low**（自己创建的目录，icacls 静默、0.07s）。

## 21. v1.5.0：企业级流水线（项目 / 阶段 / 闸门 / 研讨会 / WBS / Tool ACL）

### 数据底层
| 表 | 作用 |
|---|---|
| `projects` | 项目主体（active/blocked/done） |
| `project_stages` | 9 个阶段，创建时一次性落库为 pending |

`tasks` 增 `project_id` / `stage`，复用原判据与证据链。

### 状态机写死在触发器
```
trg_stage_no_skip       上一阶段非 done → 置 active 直接 ABORT('StageSkipped')
trg_stage_gate_guard    done 前必须「有通过闸门」且「无未通过/被否决闸门」→ ABORT('GateNotPassed')
trg_gate_veto_ins/upd   任一闸门 state='vetoed' → 项目 blocked、阶段 blocked
```
实测：跳阶段 `StageSkipped`；无闸门直接结束 `GateNotPassed`；法务否决 → `projects.state='blocked'`。

### 12 个角色 + 专属交付物 + 否决权 + Tool ACL
- 新增：产品经理(product)、架构师(architect)、审计/合规(audit)、运维/SRE(ops)、市场/增长(growth)、法务(legal)；
- `role_templates.deliverable`（charter.md / architecture.md / release_checklist.md …）、`veto`（产品/架构/审计/QA/运维/法务 = 1）；
- `app/tools_acl.py`：`db_query` 只允许 SELECT/WITH/PRAGMA，出现 UPDATE/DELETE/DROP 等 → `PermissionError` + 审计 `tool_denied`；未绑定工具同样拒绝。

### 研讨会（强制四轮）
12 条发言：1 提案 + (质询+风险)×3 + 1 修订 + (表决)×4；架构/QA/审计必须留下 risk 才放行。

### WBS 与 DAG
按标签裁剪：只有开发 → `T1`；开发+文案 → `T1 → T2 → T3`；`can_start()` 阻止依赖未完成的任务启动（实测 `DAGBlocked`）。

- 字数判据**非阻断**；显式字数（如 400-600）照办，未写则默认 600-1500；
- **取消自动扩写重试**（`repair.py` 直接返回 `auto-repair disabled (v1.5)`）。

模型不可用时自动回落模板（脚注标注「模板生成」），流程不中断。

### 4-6 阶段真执行
- 阶段 3 产出 WBS 后，阶段 4 按 WBS **自动建 task**（写 `project_id`/`stage`），再调 ACP 真跑；
- 阶段 5 对产物做 `py_compile` + 限时运行，日志写进 `05_test.md`；
- 阶段 6 校验 WBS 完成度与任务状态，任一失败 → 项目 `blocked` 并停摆。

实测（P-913861c4d2ca）：
```

05_test.md：py_compile 通过；无参退出 2；--help 退出 0，输出已捕获
9/9 阶段 done，产物齐全
```

### 本轮踩的坑
1. `execute_run` 只从 `assigned` 推进状态机 → 需先 `run_spawned`，否则任务停在 todo（首轮 47,852 token 白跑）；
2. 阶段重跑必须先清掉旧的未通过闸门，否则触发器永远不许 done；
3. 发布项（ops）不该进 build 的 WBS，删除后 build 只跑开发任务；
4. 失败即熔断：build/test/accept 任一不过 → 项目 blocked + 抛错，不再假装往下走。
