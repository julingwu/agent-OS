## 升级与回滚

1. 升级前：`python -c "import sqlite3;s=sqlite3.connect('data/oa.db');d=sqlite3.connect('data/oa.db.bak');s.backup(d)"`
2. 启动：`uvicorn app.main:app --port 8077`（Windows 一键：`~/bin/agentos-server.cmd`）
3. 回滚：停服务 → 恢复 `.bak` → **同时删除 `oa.db-wal` / `oa.db-shm`**（否则日志重放会把旧页写回去）→ 用上一版程序启动

## 已知边界

- 企微群 webhook 由管理员在界面填写，本版不含真实群 key；未配置时事件只记账、不投递。
- `DEPLOY.md` 的 Linux 方案只做了配置与键名核对，未在真实 Linux 主机跑过（上云时再排雷）。
- 红线仍只扫文本产物：图片/PDF 未 OCR，禁用词不做同义词扩展。
- MCP 外部工具仅支持 HTTP 形态（DSH 只声明 `mcpCapabilities.http`）。
- 组织经验与评测集仍是组织级共享，未按租户切分。
