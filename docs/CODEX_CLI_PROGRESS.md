不包含账户标识、设备标识、会话内容、绝对路径、服务凭据、认证状态文件或原始运行日志。

## 已实现

- 增加独立 Codex CLI 推理适配器，使用独立登录目录；由用户在官方登录页面完成认证。
- 从 CLI 模型目录动态读取模型与支持的推理级别；界面分开选择模型和推理强度。
- 使用结构化输出按工具名约束参数对象，分派前再次校验；保留应用自身的工具执行与审批边界。
- CLI 等待期间发送进度事件，界面定期校对会话状态，减少重连后长时间显示思考的情况。
- 桌面桥支持环回 HTTP WebSocket；远程连接继续使用 TLS 证书校验。
- 修正 Windows cmd 命令传参，避免常见嵌套引号被 CRT 转义破坏。
- 并行排空命令 stdout/stderr，限制保留的输出大小，避免大量输出堵住管道。
- 本地命令执行期限限制为 1–150 秒，桥等待额外留出 10 秒；超时时尝试终止命令进程树。
- 审批完成后广播终态事件，使其他客户端能移除已处理审批卡片。
